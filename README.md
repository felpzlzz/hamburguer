# Heroic Burger — Next.js

Conversão do HTML fornecido para Next.js/React.

## Rodar
```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Observações
- O checkout continua abrindo o WhatsApp com o pedido formatado.
- As imagens continuam usando URLs do Unsplash do HTML original.
- O mapa continua usando o embed do Google Maps presente no arquivo original.
- Não há backend de pedidos/pagamentos: o comportamento original era somente front-end + WhatsApp.
